# dvd-rental-business-analysis

**Project Overview**

This project is based on the PostgreSQL DVD Rental sample database and demonstrates SQL skills from a business and data analysis perspective.
The main objective was to answer common business questions related to customer behavior, revenue, rentals, and movie performance while practicing SQL in realistic analytical scenarios.
As the next stage of the project, the data was also visualized in Power BI to create an interactive business dashboard.

**Technologies Used**

- PostgreSQL
- SQL
- Power BI

**Project Goals**

- Analyze customer spending and rental activity.
- Identify top-performing customers and movies.
- Segment customers using SQL CASE statements.
- Practice writing business-oriented SQL queries.
- Build a foundation for creating interactive dashboards in Power BI.


**Business Questions Answered**

The project answers practical business questions such as:

- Which customers spent the most money?
- Which customers rented the most movies?
- Which customers never rented a movie?
- Which customers never made a payment?
- What is the average payment amount per customer?
- Which movie ratings are the most common?
- How can customers be segmented based on spending?
- How can customers be segmented based on rental activity?
- Which movies have never been rented?
- Which movie categories generate the highest revenue?
- Which movies generate the highest revenue?
- Which customers spend more than the average customer?

**SQL Skills Demonstrated**

- SELECT statements
- Filtering with WHERE
- Aggregate functions (SUM, COUNT, AVG)
- GROUP BY and HAVING
- ORDER BY
- INNER JOIN
- LEFT JOIN
- CASE statements
- Common Table Expressions (CTE)
- Business-oriented SQL analysis

 **Power BI Dashboard**

 The project also includes an interactive Power BI dashboard built using the DVD Rental database.

Dashboard features:

- Total Revenue KPI
- Total Rentals KPI
- Active Customers KPI
- Average Payment KPI
- Top 10 Customers by Revenue
- Rentals by Film Category
- Rentals by Rating
- Monthly Revenue Trend

Interactive slicers:

- Rental Month
- Movie Rating
