# dvd-rental-business-analysis

**Project Overview**

This project is based on the PostgreSQL DVD Rental sample database and demonstrates SQL skills used in business data analysis.
The main goal of the project is to answer common business questions related to customer behavior, payments, rentals, and movie performance while practicing SQL from a data analyst's perspective.


**Technologies Used**

- PostgreSQL
- SQL
- Power BI (dashboard planned as the next stage of the project)


**Project Goals**

- Analyze customer spending and rental activity.
- Identify top-performing customers and movies.
- Segment customers using SQL CASE statements.
- Practice writing business-oriented SQL queries.
- Build a foundation for creating interactive dashboards in Power BI.

**Motivation**

I created this project to strengthen my SQL skills and apply them to practical business scenarios. My goal is to continue developing as a data analyst by combining technical knowledge with business understanding and data-driven decision making.

**Bussiness Questions Answered**

- Which customers spent the most money?
- Which customers rented the most movies?
- Which customers never rented a movie?
- Which customers never made a payment?
- What is the average payment per customer?
- Which movie ratings are the most common?
- Which movie categories generate the highest revenue?
- Which movies generate the highest revenue?
- How can customers be segmented based on spending?
- How can customers be segmented based on rental frequency?
